1. VYV Équipement Médical — Inventory Optimization

Role: Supply Chain Analytics & Optimization
Impact: Identified EUR 300k in recoverable working capital across 61 agencies

Overview

Analyzed 4,411 article-by-agency inventory pairs across 61 agencies and 242 depots. Built Python/SQL data pipeline and custom dashboard to visualize stock levels, turnover rates, and distribution inefficiencies.

Technical Stack

  • Python: ETL pipeline for data extraction and analysis
  • SQL: Complex queries for multi-level inventory analysis
  • Custom Python Dashboard: Real-time visualization of depot-level stock positions
  • Optimization Analysis: Sensitivity analysis identifying cost drivers

Key Achievement

Sensitivity analysis ranked inventory imbalances as the primary cost driver, enabling targeted working capital optimization across the depot network.

3. Parkinson's Screening — Machine Learning Classification

Role: ML Engineer
Performance: 83.3% held-out test accuracy

Overview

Developed a machine learning system to screen for Parkinson's disease using hand-drawn spirals and voice measurements. Implemented multiple classification algorithms and deployed as a live-prediction web application.

Technical Approach

  • Feature Engineering: Extracted diagnostic features from spiral drawings and voice recordings
  • Model Comparison: Logistic Regression, Random Forest, SVM, Multi-Layer Perceptron
  • Validation: Cross-validation with held-out test set evaluation
  • Deployment: Live-prediction web application for real-time screening

Tools & Libraries

  • scikit-learn: Model training and cross-validation
  • pandas: Data processing and feature engineering
  • Python: Complete ML pipeline from data loading to deployment
