4. DrozyAI — On-Device Drowsiness Detection with LLM Advisor

Role: Co-builder (team of four, ASUS Local AI Hackathon, 24 h); original idea
Performance: 513 ms end-to-end time-to-alert, fully on-device

Overview

An offline driver-safety system that fuses smartwatch heart-rate variability (RMSSD) with facial video to detect drowsiness. A local LLM (Llama 3.2 3B via Ollama) explains each alert, while deterministic rules decide the action, so the model never controls safety-critical decisions.

Technical Approach

  • Multimodal fusion: gradient boosting baseline and GRU/TCN sequence models over watch and video features
  • Advisor design: rule-based action selection, with the LLM producing structured JSON explanations and a fallback if it fails
  • Evaluation: participant-separated 5-fold cross-validation across 19 drivers and 35 sessions, to avoid leakage between a driver's train and test data

Stack

  • Python, Ollama, scikit-learn, Garmin Connect companion (HTTPS), iOS relay app

5. Cal'm — Safe Route Home (Safety-Aware Walking Routes)

Role: Team project, hackathon prototype [ton rôle précis]
Type: Night-time walking app for UC Berkeley students

Overview

A walking-route app that answers a simple question: the fastest route is not always the safest. It computes a route using open data on street lighting, nearby help points and late-night activity, and explains why it chose it.

Technical Approach

  • Walking graph built from OpenStreetMap with per-segment safety features (lighting, POIs, crime and 311 data)
  • A* routing with a safety-aware cost, returning an explained alternative to the fastest path
  • Gemini used only to translate between text and structured inputs, never to compute routes or scores

Stack

  • Python, FastAPI, osmnx, Gemini API, Render deployment, JavaScript frontend
